# First emitters

Phase C of the roadmap delivered the **first official emitters** (transpilers) for AI Parlance. They live in the monorepo as Preview targets — not npm-published packages yet, but real Core AST → artifact pipelines you can run with `aip emit`.

---

## What “first transpiler” means here

Historically, the marketing site only had an **illustrative** playground. The language was specification-only.

With Phase C **M3–M5** and the post-M6 **Go** follow-up, the project shipped its first **reference emitters**:

| Order | Target | Package | CLI |
|---|---|---|---|
| 1st concrete emit | **PostgreSQL DDL** | `@aiparlance/sql` | `aip emit sql` |
| 2nd | **OpenAPI 3** | `@aiparlance/openapi` | `aip emit openapi` |
| 3rd | **TypeScript** | `@aiparlance/typescript` | `aip emit typescript` |
| 4th (2nd app backend) | **Go** | `@aiparlance/go` | `aip emit go` |

PostgreSQL was the **first** emitter because the docs treat it as the primary SQL dialect. OpenAPI and TypeScript completed the first multi-target wave; **Go** is the second application-backend emitter (structs, thin handlers, auth middleware stubs).

Together with `aip parse` and `aip validate`, this is the Core **reference toolchain**.

---

## Pipeline

```txt
.aip source
  → parse (AST)
  → validate (MUST rules)
  → emit sql | openapi | typescript | go
```

One Core spec feeds all Preview emitters. Naming (snake_case, FK `*_id`, plural tables) stays aligned across SQL, OpenAPI, and Go `json` tags.

---

## What each emitter produces

### PostgreSQL (`aip emit sql`)

- `CREATE EXTENSION IF NOT EXISTS pgcrypto`
- `CREATE TABLE` per `entity` (implicit `id`, timestamps; `deleted_at` when `soft_delete`)
- Types, `UNIQUE` / `NOT NULL`, enum `CHECK`s, `belongs_to` foreign keys

Golden: [`transpilers/sql/fixtures/minimal.sql`](https://github.com/eudameron/aiparlance/blob/main/transpilers/sql/fixtures/minimal.sql)

### OpenAPI 3 (`aip emit openapi`)

- Schemas `Entity` / `EntityCreate` / `EntityUpdate`
- CRUD paths when `crud Entity` is declared
- Optional `securitySchemes` from `app.auth`

Golden: [`transpilers/openapi/fixtures/minimal.openapi.json`](https://github.com/eudameron/aiparlance/blob/main/transpilers/openapi/fixtures/minimal.openapi.json)

### TypeScript (`aip emit typescript`)

- Interfaces `Entity` / `EntityCreate` / `EntityUpdate`
- Runtime type guards (`isEntity`, `isEntityCreate`) — zero runtime deps
- Thin `entityPaths` helpers when CRUD is present

Golden: [`transpilers/typescript/fixtures/minimal.ts`](https://github.com/eudameron/aiparlance/blob/main/transpilers/typescript/fixtures/minimal.ts)

### Go (`aip emit go`)

- Structs `Entity` / `EntityCreate` / `EntityUpdate` with `json` tags
- Thin `net/http` CRUD handler stubs + path helpers when `crud` is declared
- `AuthMiddleware` stubs from `app.auth` (Bearer / API key / session cookie)

Golden: [`transpilers/go/fixtures/minimal.go`](https://github.com/eudameron/aiparlance/blob/main/transpilers/go/fixtures/minimal.go)

## Try it in one minute

```bash
git clone https://github.com/eudameron/aiparlance.git
cd aiparlance && npm ci && npm run build

node packages/cli/dist/cli.js emit sql examples/minimal.aip
node packages/cli/dist/cli.js emit openapi examples/minimal.aip
node packages/cli/dist/cli.js emit typescript examples/minimal.aip
node packages/cli/dist/cli.js emit go examples/minimal.aip
```

## Honest limits (v0.1 Preview)

- Language remains **draft**; emitters cover **Core** (`app`, `entity`, `crud`, `validation`, field modifiers).
- Infra / Security / Behavior blocks in richer examples are not fully parsed yet.
- No Nest/Express/Chi lock-in — TypeScript and Go emits stay thin (stdlib / interfaces).
- Site playground is still **illustrative** and must not be confused with these packages.

Matrix status: [Specification § Transpiler matrix](/en/specification#transpiler-matrix). Next: Infra/Security/Behavior parse depth.
