# Exemplos

Todas as specs de referência ficam em [`examples/`](https://github.com/eudameron/aiparlance/tree/main/examples) e são validadas no CI (`npm test` / `scripts/examples.test.ts`).

| Spec | Foco | Página |
|---|---|---|
| [`minimal.aip`](https://github.com/eudameron/aiparlance/blob/main/examples/minimal.aip) | Menor smoke Core + goldens de emit | [Mínimo](/pt/examples/minimal) |
| [`blog-crud.aip`](https://github.com/eudameron/aiparlance/blob/main/examples/blog-crud.aip) | CRUD completo de blog | [Blog CRUD](/pt/examples/blog-crud) |
| [`inventory-crud.aip`](https://github.com/eudameron/aiparlance/blob/main/examples/inventory-crud.aip) | Inventário + jobs / filas | [Inventory CRUD](/pt/examples/inventory-crud) |
| [`mysql-minimal.aip`](https://github.com/eudameron/aiparlance/blob/main/examples/mysql-minimal.aip) | Dialeto MySQL (`aip emit mysql`) | [MySQL mínimo](/pt/examples/mysql-minimal) |
| [`crm-reference.aip`](https://github.com/eudameron/aiparlance/blob/main/examples/crm-reference.aip) | CRM — policies, API, workflows | [CRM referência](/pt/examples/crm-reference) |
| [`ops-reference.aip`](https://github.com/eudameron/aiparlance/blob/main/examples/ops-reference.aip) | Seed, lifecycle, jobs, `ai_context` | [Ops referência](/pt/examples/ops-reference) |

Tutorial do blog: [Walkthrough CRUD](/pt/crud-walkthrough).

```bash
node packages/cli/dist/cli.js validate examples/minimal.aip
node packages/cli/dist/cli.js emit sql examples/blog-crud.aip
node packages/cli/dist/cli.js emit mysql examples/mysql-minimal.aip
node packages/cli/dist/cli.js emit workers examples/inventory-crud.aip
```
