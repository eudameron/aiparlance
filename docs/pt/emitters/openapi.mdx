## O que gera

OpenAPI 3.0.3 JSON: schemas, paths CRUD, `api.prefix`, auth, `security` por operação a partir de `policy`, `x-aip-cors` / `x-aip-rate-limit`, notas de soft-delete, query de paginação, schema `Error` compartilhado, 409/429.

## ✅ Passou

| ID | Objetivo |
|---|---|
| `A1`–`A9` | Schemas de entidade + semântica de soft-delete no contrato |
| `B1`, `B2`, `B4` | required/optional, unique→409, `format: email` |
| `D1`–`D7` | CRUD, prefix, cors, rate_limit, paginação, erros tipados, JSON |
| `E1`–`E6` | Auth, security de policy, scopes de owner_or_manager, 401/403 |
| `H3`–`H5` | Goldens / CI / naming |
