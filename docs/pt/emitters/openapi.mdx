## O que produz

OpenAPI 3.0.3 JSON: schemas, paths CRUD, `api.prefix`, schemes de auth.

## Objetivos — passando hoje

- A1–A8 schemas Create/Update
- B1 required
- D1 CRUD + D2 prefix + D7 JSON
- E1 securitySchemes
- H3–H5

## Objetivos — lacunas / próximos

- E2–E6 policy → security por operação
- D3–D6 cors, rate_limit, paginação, erros
- I1–I2 client / paridade
