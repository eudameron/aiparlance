## O que produz

DDL PostgreSQL: `CREATE TABLE`, índices, seeds. Dialeto SQL primário.

## Objetivos — passando hoje

- A1, A4–A8 colunas / FKs / enums
- B1–B2 NOT NULL / UNIQUE
- C1–C3 DDL, índices, seeds
- C6 dialeto postgres
- H3–H5 CI + naming

## Objetivos — lacunas / próximos

- C4/C5 migrations versionadas
- A9 semântica de soft-delete na leitura
- B3/B4 tipos/validação mais ricos
