# @aiparlance/python

Python dataclasses (`Entity` / `EntityCreate` / `EntityUpdate`) with snake_case fields and `Optional` for optional properties. Stdlib `typing` only.

```ts
import { emitPython } from "@aiparlance/python";

process.stdout.write(emitPython(doc));
```
