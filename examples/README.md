# Examples

Reference AI Parlance (`.aip`) specs for learning, validation, and (future) transpiler tests.

| File | Description |
|---|---|
| [minimal.aip](minimal.aip) | Smallest valid v0.1 spec (`app` + one entity + CRUD) |
| [crm-reference.aip](crm-reference.aip) | CRM with users, leads, tasks, policies, API, and workflows |
| [ops-reference.aip](ops-reference.aip) | Infra + Behavior extras: `timestamps`/`soft_delete`, `seed`, `validation`, `lifecycle`, `job`, `queue`, `ai_context`, `if`/`reject`/`dispatch` |

Documented at [docs.aiparlance.org](https://docs.aiparlance.org) · [source on GitHub](https://github.com/eudameron/aiparlance/tree/main/examples).

Normative grammar: [spec/v0.1/grammar.ebnf](../spec/v0.1/grammar.ebnf).
